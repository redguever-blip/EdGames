Guia de Hospedagem Grátis & PIX

Siga este passo a passo interativo para colocar este site no ar na internet sem gastar nada e receber pagamentos pelo seu celular!

1

Baixar e Salvar o Arquivo do Site no Celular

Você precisa guardar o código deste site em um único arquivo chamado index.html no armazenamento interno do seu celular.

Dica: Copie todo o código deste artefato gerado e cole em um app de notas ou editor de texto no celular (como QuickEdit ou Acode para Android / iOS) e salve com o nome index.html.

2

Criar Conta Grátis no GitHub (Pelo Navegador)

O GitHub é a maior plataforma de hospedagem de projetos do mundo e permite publicar sites de graça para qualquer pessoa acessar no mundo.

  1. Acesse o site github.com no navegador do seu celular.
  2. Clique em Sign Up e crie sua conta gratuita.
  3. Confirme o código recebido no seu e-mail.
3

Criar um Repositório e Enviar o Arquivo

Publicando o arquivo diretamente pelo celular no GitHub Pages:

  1. No GitHub, toque no ícone de + e selecione New repository.
  2. Dê o nome do projeto (Exemplo: meu-site-de-games) e marque como Public.
  3. Clique em Create repository.
  4. Na tela seguinte, toque no link uploading an existing file.
  5. Selecione o arquivo index.html do seu celular e toque em Commit changes.
4

Ativar o GitHub Pages (Colocar no Ar!)

Ative o servidor gratuito do GitHub para gerar o seu link público:

  1. Dentro do repositório no GitHub, clique em Settings (Engrenagem).
  2. No menu esquerdo/superior, toque em Pages.
  3. Em Build and deployment, mude a opção de None para main ou master.
  4. Clique em Save. Aguarde 1 a 2 minutos.
  5. Seu site estará no ar no endereço:
    https://seu-usuario.github.io/meu-site-de-games
5

Como Receber Pagamentos no Celular via PIX

Você pode usar qualquer banco no Brasil para receber as transferências:

  • Nubank, Mercado Pago, PicPay, Inter ou Caixa: Copie sua chave PIX no app do banco.
  • Acesse a aba Loja PIX deste site, role até o Painel do Dono e insira sua chave.
  • Quando um jogador quiser comprar ou doar, o site gera o QR Code e o PIX Copia e Cola automaticamente para o banco dele transferir direto para sua conta!
